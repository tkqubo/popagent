# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The canonical text lives at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project (issues, pull requests, discussions) you
agree to abide by its terms.

## Reporting

If you witness or experience behavior that violates the Contributor Covenant,
report it privately by opening a
[GitHub Security Advisory](https://github.com/tkqubo/popagent/security/advisories/new)
or by emailing the maintainer (see `package.json` for the listed author).
Reports are handled confidentially.
